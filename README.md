# Xonix

Browser game inspired by the classic Xonix/Qix territory-capture gameplay.

## Run locally
Open `index.html` through any static web server.

## GitHub Pages
This repository is fully static and can be published directly with GitHub Pages using the `main` branch root.

### Controls
- Keyboard: arrows or WASD
- Mobile/tablet: on-screen D-pad or swipe on the game area
- Pause button available on touch devices
